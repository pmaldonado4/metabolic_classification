# Metabolic Classification Project

This repo is focused on the development of a deep learning model that classifies accesible chromatin sites based on their relation to different metabolic states.
#### The approach is as follows:
1) Obtain embeddings using a HyenaDNA foundation model pretrained on the genomes of four metabolically diverse species (mouse, human, lemur, squirrel).
2) Perform exploratory data analysis on the features and create new features based on domain knowledge.
3) Explore different architectures and identify the best performing model.
